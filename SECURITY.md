# Security policy

ClipShelf reads clipboard data by design. Treat stored history as sensitive local data.

To report a vulnerability, do not open a public issue. Use GitHub's private vulnerability-reporting feature for the repository when it is enabled; otherwise contact the repository owner privately with a concise reproduction and impact description. You should receive an acknowledgement within seven days.

Supported version: the latest version on the `main` branch and the latest tagged release.

When reporting, do not include passwords, tokens, private files, or real clipboard history. A synthetic reproduction is enough.
